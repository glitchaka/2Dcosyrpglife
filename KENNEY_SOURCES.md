# Asset sources

This prototype deliberately uses Kenney's original CC0 artwork directly, without repainting or reinterpretation.

- Tiny Town — 16×16 — CC0: https://kenney.nl/assets/tiny-town
- Tiny Dungeon — 16×16 — CC0: https://kenney.nl/assets/tiny-dungeon

Runtime source mirrors used by the browser prototype:

- Tiny Town sample: https://raw.githubusercontent.com/GeorgeQLe/assets-2d-city/main/assets/kenney/tiny-town/Sample.png
- Tiny Town preview: https://raw.githubusercontent.com/GeorgeQLe/assets-2d-city/main/assets/kenney/tiny-town/Preview.png
- Tiny Dungeon sample: https://raw.githubusercontent.com/yurukusa/spell-cascade/15046980488631690b1c46bf348fadee18a1e19e/assets/sprites/kenney/tiny-dungeon/Sample.png

The art remains Kenney CC0 artwork. The game code and world traversal logic are project code.
